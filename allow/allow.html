让 Agent 读你的 Ahrefs

对话里的 Agent 要看 的外链和流量增长。插件会用你登录的 Ahrefs（）打开这个站的 Site Explorer，把页面上的曲线和指标读回来交给 Agent。

  • 读到的只交给你自己的对话，不进网站的共享缓存。
  • 只在插件自己打开的标签页里读，读完就关；你自己打开的 Ahrefs 标签页一概不碰。
  • Chrome 会问一次；以后随时可以在 chrome://extensions 里收回。

网站那边抓不到这个网页（跳转太多、被拦、要登录，或者要执行 JS 才有内容）。插件会在后台打开

等页面加载完，把页面上的文字、标题、链接读回来交给 Agent，读完关掉。

  • 是用你的浏览器打开的：你在 登录后能看到的内容，它也读得到——不认识的网站、不想让它看的页面，点「不允许」。
  • 读到的只交给你自己的对话，不进网站的共享缓存。
  • Chrome 会问一次（只针对 ）；以后随时可以在 chrome://extensions 里收回。
